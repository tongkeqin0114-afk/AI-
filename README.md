# AI 视频创作

极简短视频创作工作台，目标流程：

**灵感 → 参考风格 → 原创脚本 → 原始素材 → 自动剪辑 → 9:16 MP4**

## 已完成

- 极简中文创作界面
- 五段式脚本：开场核心金句 → 反常识钩子 → 大多数人的认知 + 举例说明 → 正确理解和说明 → 结尾
- OpenAI Responses API 脚本生成
- 参考视频文件的基础节奏分析：时长、画幅、镜头切换点、平均镜头时长
- 原始视频上传
- FFmpeg 自动处理：检测明显开头/结尾静音、裁切为 1080×1920、自动生成字幕、H.264/AAC MP4 导出
- Docker Compose：Next.js 前端 + FastAPI/FFmpeg 视频工作器

OpenAI 的 GPT-5.6 Luna 可通过 Responses API 使用；语音转写可进一步接入专用 transcription 模型。citeturn0search0turn1search0

## 本地运行

1. 复制环境变量：

```bash
cp .env.example .env
```

2. 在 `.env` 中填写 `OPENAI_API_KEY`。

3. 启动：

```bash
docker compose up --build
```

4. 打开：

```
http://localhost:3000
```

视频工作器：

```
http://localhost:8000/docs
```

## 说明

参考视频目前建议直接上传视频文件。普通网页链接不一定能直接取得视频媒体文件，因此网页链接字段会作为创作上下文传给脚本模型，但不会假装已经完成视频内容分析。

自动剪辑当前是“基础自动剪辑”：去除明显开头/结尾静音、竖屏裁切、字幕、MP4 导出。FFmpeg 官方文档提供了 `silencedetect` 等音频检测能力。citeturn2search1

下一阶段如果继续产品化，可加入：

- OpenAI 语音转写 + 时间戳
- 按语音节奏自动切片，而不是只裁开头/结尾
- 多素材智能选片
- BGM 上传与自动压低人声以下
- 字幕样式编辑
- 项目保存、历史版本、用户账号
- 对象存储与异步任务队列
- 生产环境鉴权、限流和大文件分片上传

注意：参考视频只用于提取高层风格/节奏信息，不复制原视频文案、独特表达或源素材。
